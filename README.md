## Executando o projeto

Instruções de como configurar e executar o projeto localmente em um dispositivo Android físico:

### Pré-requisitos

* **Android Studio** <br>
  Caso não possua: [Link de Instalação](https://developer.android.com/studio)

* **Um cabo USB** compatível com seu dispositivo Android

### Instalação

1. Clonar o repositório
```sh
git clone https://github.com/samsesz/Memori-PI.git
```

2. Abrir o projeto no Android Studio

3. Aguardar a sincronização do Gradle (pode levar alguns minutos na primeira vez)

### Rodando no celular (cabo USB)

1. No seu celular Android, ative o **Modo Desenvolvedor**:
2.  Conecte o celular ao computador via cabo USB
3.  Uma janela vai aparecer no celular perguntando se confia no computador — confirme com **"Permitir"**
4.  No Android Studio, selecione seu dispositivo na barra superior e clique em **Run ▶**

### Observações
- Os dados estão mockados (sem banco de dados em nuvem)
- Não é necessário configurar variáveis de ambiente
- Compatível com Android 7.0 (API 24) ou superior
